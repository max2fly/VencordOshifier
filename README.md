# VencordOshifier

## What is this?

This is a custom plugin for Vencord that allows you to designate your oshi, so you get desktop notifications whenever they make an announcement!

## Why?

Ever missed a spontaneous announcement of new merch, only for it to sell out before you saw it? Then this plugin is for you!

## Pre-requisites

1. Install the [vc-message-logger-enhanced](https://github.com/Syncxv/vc-message-logger-enhanced/) plugin.
2. Repeat the same steps you used to install [vc-message-logger-enhanced](https://github.com/Syncxv/vc-message-logger-enhanced/) with this repo instead. (video below)
